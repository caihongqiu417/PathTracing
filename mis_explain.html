为什么需要多重重要性采样（MIS）

一、当前算法的问题

当前代码对漫反射面做 NEE（直接光采样），对 delta 材质做 BSDF 采样，两者互斥。这会导致两类场景出问题：

问题 1：光源很小 + 材质是光滑镜面 → NEE 高方差

NEE 的问题：光源方向上 BSDF 值接近 0（光源不在反射波瓣内），每次 NEE 采样都白费。 渲染结果：噪点极多，收敛极慢。

问题 2：光源很小 → BSDF 采样命中概率低

BSDF 采样的问题：漫反射随机方向几乎不可能命中极小的光源， 偶尔命中时贡献极大（因为 pdf 很低），产生萤火虫（firefly）噪点。

问题 3：当前代码对漫反射完全丢弃 BSDF 命中光源的贡献

当前代码的 bug：漫反射面 BSDF 采样如果恰好命中光源， 因为 last_is_specular=false 而完全不计入，这段贡献就丢失了。 正确做法是用 MIS 权重把它算进去，而不是扔掉。

二、MIS 的思路

MIS 的核心思想：同时使用两种采样策略，每个样本按"它在这个策略下有多好"来加权，既不丢弃任何贡献，也不重复计算。

L_direct = w_NEE · [f(wi,wo) · Le · cosθ / p_NEE(wi)] + w_BSDF · [f(wi,wo) · Le · cosθ / p_BSDF(wi)]

权重用 Power Heuristic（幂启发式，β=2）：

w_i(x) = p_i(x)^β / Σ_j p_j(x)^β // 对于 NEE 和 BSDF 两种策略： w_NEE(x) = p_NEE(x)² / (p_NEE(x)² + p_BSDF(x)²) w_BSDF(x) = p_BSDF(x)² / (p_NEE(x)² + p_BSDF(x)²)

直觉上：哪种策略对这个采样点的 pdf 更高，它的权重就越大，说明它"更擅长"采到这个方向。

三、MIS 在不同场景下的效果

大光源 + 漫反射：NEE 和 BSDF 各贡献一半，方差都不大。
小光源 + 光滑材质：BSDF pdf 高，MIS 自动给 BSDF 更大权重，NEE 贡献极小但不浪费。

四、MIS 如何修改代码

当前代码流程（有问题）：

漫反射面： 1. NEE → 加入 L（全权重） 2. BSDF 采样 → 如果命中光源，不算（丢失！） delta 面： 1. 跳过 NEE 2. BSDF 命中光源 → 全权重加入 L

MIS 修改后的流程：

所有非 delta 面： 1. NEE 采样 x_l： w_l = p_NEE² / (p_NEE² + p_BSDF(x_l)²) L += beta * f * Le * cosθ * w_l / p_NEE 2. BSDF 采样 x_b → 如果命中光源： w_b = p_BSDF² / (p_NEE(x_b)² + p_BSDF²) L += beta * f * Le * cosθ * w_b / p_BSDF （这里需要能计算光源在 x_b 方向的 p_NEE， 即 light_sampler 需提供 PDF 查询接口）
策略采样谁需要的 PDF当前代码状态
NEE光源上的点p_NEE = prob × pdf_light已有
BSDFBSDF 分布的方向p_BSDF = BSDFSample.pdf已有
交叉查询BSDF 样本在 NEE 下的 PDFp_NEE(x_b) = 需要 LightSampler::Pdf()缺失
交叉查询NEE 样本在 BSDF 下的 PDFp_BSDF(x_l) = material.BSDF_PDF(wi)缺失
需要新增的接口：
1. LightSampler::Pdf(light_direction, hit_point) — 查询给定方向的 NEE 采样概率密度
2. Material::BSDFPdf(wi, wo) — 查询给定方向对 BSDF 采样的概率密度
这两个接口补齐后，就能完整实现 MIS。

五、MIS 的数学保证

MIS 是无偏的（期望值等于真实积分）：

E[Σ_i w_i(x_i) · f(x_i) / p_i(x_i)] = ∫ f(x) dx // 因为 Σ_i w_i(x) = 1，对任意 x 成立

同时方差远低于单策略：当某策略 pdf 高时，其权重大，其他策略权重自动缩小，避免了高方差样本的影响。

总结
当前问题：漫反射 BSDF 命中光源的贡献被完全丢弃，且没有权重，方差大
MIS 解决：两种策略各出样本，按 PDF 高低自动分配权重，既不丢失贡献也不重复计算
实现代价：需要补充 PDF 查询接口，代码量不大但需要设计好接口
